# AutoImpacto React Website

Sitio bilingüe creado con React y Vite. El idioma predeterminado es español, y hay un botón en la esquina superior derecha para cambiar a inglés.

## Ejecutar

```bash
npm install
npm run dev
```

## Estructura

- `src/App.jsx`: componente principal con selector de idioma
- `src/i18n.js`: traducciones en español e inglés
- `src/style.css`: estilos del sitio

> Nota: el contenido actual es una plantilla bilingüe. Si tienes el texto del flyer, puedo integrarlo directamente en el sitio.
